COMMON PATTERNS TO FIX (for the agent)
---------------------------------------
1.  time.sleep()                → expect(locator).to_be_visible() or to_have_count()
2.  wait_for_load_state(        → expect() web-first assertions
    "networkidle")
3.  assert locator.is_visible() → expect(locator).to_be_visible()
4.  CSS selectors in tests      → get_by_role(), get_by_label(), get_by_placeholder()
5.  No try/finally cleanup      → wrap POST/create in try/finally, DELETE in finally block
6.  Hardcoded task titles       → f"Task {uuid.uuid4()}"
7.  raise NotImplementedError   → actual implementation required
8.  Wrong fixture scope         → scope="module" or scope="session" where appropriate
9.  return instead of yield     → yield + finally cleanup block in fixtures
10. Context not disposed        → ctx.dispose() or browser_context.close() in finally
11. Wrong assertion value       → correct HTTP status (401 not 200, 400 not 201, etc.)
12. Missing allure decorators   → @allure.epic / @allure.feature / @allure.story on classes
